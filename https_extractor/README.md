```text
This directory contains utilities designed to download files and assets from HTTPS URLs. They were originally created to extract official game data to support a Japanese localization project.

### HTTPS Extractor (`https_extractor.py`)
Downloads files from any specified URL.
*   **Single mode:** Input the URL directly in the terminal.
*   **Batch mode:** Uses a `urls.txt` file (one link per line). If the file is missing, the script will prompt to auto-generate it.

## How to use
# Run Extractor
python https_extractor.py
```
